What exists, and what needs a home

Read the status first. “In app now” means the page or control exists, not that every edge case is solved. “Partial” means users can do some of the task, but an important part is missing. “Proposed” means we are deciding whether and where it belongs—nothing has been built or approved. The question on each card is the decision I need from you.

Suggested order: start with Chat Memory and Sources—should they be one place or two? Then look at Personal Memory versus AI-saved notes, followed by AI connections versus extension controls. Projects and Timeline can wait if their purpose is not yet convincing.

03 / Gate 8B

What each flow must explain

A state is a moment that needs its own explanation—for example, an upload waiting offline is different from an upload that failed. “Present” means some UI exists, not that the underlying behavior is proven. “Partial” means the explanation or recovery path is incomplete. “Not built” means there is no intentional experience yet. This is design inventory only; Gate 9 must verify the safety guarantees underneath it.
