MEMORY

Privacy notice

Effective September 17, 2026

Sherry Capture is a private browser extension that copies supported AI conversations into your Sherry workspace so you can retrieve context across AI providers.

What the extension handles

  • Visible user messages and AI responses on supported ChatGPT, Claude, and Gemini pages.
  • Conversation titles, page URLs, message order, timestamps, and links.
  • Attachment names and metadata when attachment capture is enabled.
  • Your Memory account email and authentication session.
  • Sensitive information—including health or financial information—when it appears in a captured conversation.
  • Limited technical information only when Firefox technical-data permission is enabled.

Deleted messages and temporary chats are not intentionally collected by default. Attachment capture is off by default.

Why the data is used

Captured information is used only to provide your Memory workspace: durable conversation storage, summaries, reviewable memory claims, retrieval, source attribution, synchronization, diagnostics, deletion, and export.

Where data is stored

The extension sends captured data over HTTPS to the Memory ingestion service hosted on Cloudflare Workers. Raw archives are stored in a private Cloudflare R2 bucket. Structured workspace data and account authentication are hosted in Supabase.

Passwords, API keys, private keys, payment-card numbers, and certain labelled credentials found inside captured content are automatically redacted before durable storage. Your Memory account password is sent directly to Supabase for authentication and is not saved by the extension. Session tokens remain in your browser profile and are excluded from diagnostic exports.

Your controls

You can pause capture, control attachment and temporary-chat capture, disconnect cloud synchronization, inspect source conversations, export workspace data, and delete stored conversations or generated summaries. Disconnecting synchronization does not automatically delete data already stored in Memory.

Sharing and retention

Memory does not sell captured data or use it for advertising. Cloudflare, Supabase, and a user-selected summarization provider process data only as needed to provide the configured service. Data remains until you delete it or it is removed under the configured retention policy.

Prototype status

This is an unlisted prototype for private testing. Its privacy controls and storage design will be reviewed again before any public release.
